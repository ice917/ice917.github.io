## 形态

直觉方案：搞空间推理的合成数据，微调一个 VLM。这条路线确实有人走通了——但把证据摊开按等级看，结论要谨慎得多。

**训练方法的证据分级：**

| 方法 | 声称效果 | 等级 |
| --- | --- | --- |
| 合成 SFT（SpaRE，ACL 2025） | 空间推理最高 +49% | **B**（会议论文声称） |
| 程序化合成（SPRITE，2025） | 30 万+样本 | B |
| RLVR/GRPO（Spatial-R1，2025） | VSI +7.4，超 GPT-4o | B |
| 可验证奖励优于偏好奖励（Patterns 2025） | RLVR 综述结论 | **A** |
| 小模型 RL 即有效（IEEE L-CSS 2026） | 1.5B 模型长程规划 70%，胜 14B 基线 | **A** |
| RL+可验证奖励涌现反思（DeepSeek-R1, Nature 2025） | AIME ~79.8% | **A** |

注意断层：**"合成数据直接提升空间能力"的核心证据全部停留在 B 级**；A 级证据支持的是"可验证奖励的 RL 有效"——而这恰好指向第三章的范式。

## 8GB 笔记本的硬边界（C 级社区实测）

| 任务 | 结论 |
| --- | --- |
| 2B-4B VLM 4bit QLoRA | 可行（峰值 6-8GB） |
| 7B-8B QLoRA | 勉强（batch 1 + 梯度检查点） |
| VLM GRPO | **不可行**（下限 12-16GB） |
| 图像生成模型 LoRA（Qwen-Image-2.1） | 不可行（下限 10GB，且非商用许可） |
| Cosmos3-Nano（16B） | 跑不动（官方目标 H100 级） |

顺带纠偏一个流传的说法：**FLUX 是 Black Forest Labs 的**，NVIDIA 只是合作做了 ComfyUI/FP8 优化；不存在"黄仁勋开源的 FLUX"。

## 背答案风险与防线

训练最大的暗坑：**模型背组合而不是学关系**。Information Fusion 2024（A 级）实证了"组合暴露高估泛化"。防线四道：

1. **CoGenT 零重叠切分**：训练集只出部分属性组合，测试集出未见组合，脚本断言零重叠；
2. **结构先验注入**：显式覆盖对称/可逆关系（左↔右、A 在 B 上↔B 在 A 下）——KBS 2026（A 级）证明结构先验注入后 OOD 100% vs Transformer <10%；
3. **外部基准复测**：VSI-Bench/SIBench 子集（训练期从未见过）看真实迁移；
4. **改值重测**：测试卡坐标/尺寸整体平移后重问，背答案的模型分数暴跌。

## 一句话结论

训练路线**能走但不省钱**：证据等级不齐、8GB 只够 SFT、RL 阶段必须上云或换范式。真正 A 级背书的反而是"可验证奖励"——这就引出下一章：与其教模型学会算，不如给它一个永远算不错的裁判。
